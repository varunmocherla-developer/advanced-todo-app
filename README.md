## ✨ Key Features
- **Dynamic UI:** Smooth animated background with glassmorphism effects.
- **Persistence:** LocalStorage integration to keep data safe across refreshes.
- **Theme Toggle:** Full theme support (Dark/Light Mode).
- **Optimization:** Implemented `useMemo` for stable UI content and performance.

## 🛠️ Tech Stack
- **Frontend:** React.js (Hooks, Functional Components)
- **Styling:** CSS3 (Flexbox, Glassmorphism, Keyframes)
- **Icons:** React Icons
- **Deployment:** Vercel
